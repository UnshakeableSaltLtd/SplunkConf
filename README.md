# Splunk .Conf Presentation Repository

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Supporting material and collateral for Splunk .Conf presentations by **UnshakeableSaltLtd**.

This repository holds slides, demo code, scripts, Splunk Apps, Splunk Add-ons, and supporting documentation for sessions delivered at Splunk .Conf events.

---

## Repository Structure

``` code
SplunkConf/
├── conf25/                   # Splunk .Conf 2025 sessions
│   └── PLA1125/
│       ├── README.md         # Session overview and abstract
│       ├── slides/           # Presentation slides (PDF / PPTX)
│       ├── demos/            # Demo scripts (bash, Python, PowerShell)
│       └── images/           # Supporting images and diagrams
│
├── conf26/                   # Splunk .Conf 2026 sessions
│   ├── SEC1053/
│   └── SEC1215/
│
└── apps/                     # Splunk Apps and Add-ons
    └── TA_ResponseActions/
        ├── README.md
        ├── default/          # Splunk default configuration
        ├── metadata/
        ├── bin/              # Scripts (Python, bash, PowerShell)
        └── lookups/

```

## Content Types

This repository contains:

- 📊 **Presentation slides** — PDF and/or PPTX format
- 🐍 **Python scripts** — Demo code, Splunk SDK examples, and automation
- 🐚 **Bash scripts** — Shell automation and helper scripts
- 💻 **PowerShell scripts** — Windows automation and Splunk integration scripts
- 📦 **Splunk Apps & Add-ons** — Full Splunk app packages ready for installation
- 📖 **Markdown documentation** — Guides, architecture diagrams, and references
- 🖼️ **Images and diagrams** — Architecture diagrams, screenshots, and visual aids
